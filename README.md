# MAX Messenger Web • GREEN-API Client

Тестовое задание на позицию **Фронтенд разработчик React** для компании **GREEN-API**.

Интерфейс веб-чата, разработанный по мотивам [web.max.ru](https://web.max.ru/), позволяющий авторизоваться по учетным данным GREEN-API, создавать диалоги по номеру телефона, отправлять текстовые сообщения и принимать ответы в реальном времени через HTTP API.

🔗 **Демо онлайн (Live Demo):** [https://salomh46-rgb.github.io/green-api-chat-/](https://salomh46-rgb.github.io/green-api-chat-/)

---

## 🛠 Стек технологий

- **React 19** + **TypeScript** — строгая типизация интерфейсов и компонентов
- **Vite** — быстрая сборка и Hot Module Replacement (HMR)
- **Tailwind CSS v4** — современная адаптивная верстка под десктоп и мобильные устройства
- **Lucide Icons** — векторные иконки интерфейса
- **Web Audio API** — нативное звуковое уведомление о входящих сообщениях без внешних зависимостей

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:5173`.

### 3. Сборка для продакшена
```bash
npm run build
npm run preview
```

## 💡 Реализованный функционал

1. **Авторизация:**
   - Ввод `idInstance` и `apiTokenInstance` (с возможностью указать кастомный кластер API).
   - Проверка статуса инстанса через `getStateInstance` перед входом.
   - Сохранение сессии в `localStorage` для предотвращения сброса при перезагрузке.

2. **Работа с диалогами:**
   - Создание нового чата по номеру телефона (с автоматической нормализацией к формату `chatId: {phone}@c.us`).
   - Поиск и фильтрация диалогов по номеру телефона или тексту последнего сообщения.
   - Локальное сохранение истории диалогов и сообщений для каждого инстанса.

3. **Отправка сообщений (`SendMessage`):**
   - Оптимистичное отображение исходящего сообщения в ленте со статусом отправки.
   - Отправка по нажатию `Enter` (перенос строки по `Shift + Enter`).
   - Индикация статусов: часы (отправка), одна галочка (отправлено на сервер), две синие галочки (доставлено).

4. **Получение сообщений (`ReceiveNotification` + `DeleteNotification`):**
   - Фоновый опрос очереди через кастомный хук `useNotifications`.
   - При получении сообщения типа `incomingMessageReceived` сообщение автоматически добавляется в соответствующий чат (или создается новый чат, если входящее сообщение от нового контакта).
   - Квитирование (подтверждение) через `DeleteNotification` для очистки очереди на сервере GREEN-API.
   - Экспоненциальный/адаптивный интервал (backoff): опрос каждые 2.5 сек при пустой очереди, мгновенная проверка следующего при наличии входящих, и задержка 5 сек при сбоях сети для предотвращения лишней нагрузки.
   - Легкий ненавязчивый звук оповещения через браузерный `AudioContext`.

## 📱 Адаптивность

Интерфейс спроектирован по принципу Mobile-First / Responsive:
- **Десктоп:** Двухколоночный интерфейс (боковая панель с чатами + активный диалог).
- **Мобильные экраны:** Автоматическое переключение между списком чатов и открытым диалогом с кнопкой «Назад».
